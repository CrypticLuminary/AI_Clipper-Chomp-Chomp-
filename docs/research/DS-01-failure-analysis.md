# DS-01 failure analysis
1. Tight budget: at 20/hour adaptive hits 92 vs weighted/RRF 113; no_balance 116 and no_explore 101. Equal-score rank ties plus fixed .35 bonuses and reserved gap probes displace evidence-rich candidates. Remedy: start with simpler RRF/weighted and treat exploration as separately budgeted, test on held-out silent events.
2. Fixed context: at 40/hour 87/144 context hits vs adaptive-window 134, same core hits. Fixed windows truncate synthetic 16s speech with 4s each side. Adaptive context helps on this fixture but risks review inflation. Test matched footage budgets.
3. Association: fixed_assoc reaches 98/144 at 20 vs typed 92. Typed grouping separates nearby distinct types in unit tests, but longer context can contain multiple events; multi-event-window count is not false merge. Need provenance-based independent association labels, overlapping same-type distractors and long linked stories.
4. RRF and weighted tie across these fixtures: groups mostly single lane, no strong test of cross-modal fusion. Rank ties can over-promote singleton lanes or repeated tied noise. Test uneven lane densities, no chat/speech, uncalibrated score scales, real distractors and correlation.
5. Silent exploration has no evidence and may waste budget; never classify it as discovered entertainment. Missing data is not a negative signal. Explicit links can be wrong; source/producer validation and human review still needed.
6. O(KN) selection, runtime overhead vs baseline; stress beyond 800 rows and optimize only with measured profiling. No full repo test or real VOD evaluation.
