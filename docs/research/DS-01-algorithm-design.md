# RADAR-X v0 specification
Evidence: immutable source ID, integer half-open span <=60s, lane, kind, producer, strength, description, optional upstream link. SHA256 of canonical JSON fields is ID. Only same-source rows in explicitly available lanes. Identical rows deduplicated. No raw cross-lane confidence calibration.
Association: sort by start/end/ID. Typed mode groups same lane/kind/producer if intervals overlap; explicit common link permits gaps <15s. Bound group span <=60s. Other experimental modes: fixed anchor distance 2.6s, overlap-only, none. Last-group per key; no general graph or learned similarity. Keep distinct proposals even if their contexts overlap. Explicit link must be upstream inferred, never gold label.
For group g, lane strength s_l=max member strength, rank r_l by decreasing s_l, ties competition rank. Define q_l=1-(r_l-1)/N_l. Weighted method mean(q_l) with equal observed-lane weights. RRF sum_l 1/(60+r_l). Adaptive base max(q_l), plus .35/(1+n_block)+.35 max_l 1/(1+n_lane) when balancing. Select largest score with deterministic anchor/id tie breaks; update counts. Reserve min(floor(K/10), number_of_5min_blocks-1) for largest uncovered temporal gaps; no gold label or evidence on exploration proposals. Hard count <=K. No forced final clips.
Context: union core plus lane-specific pre/post pad, capped to 60s preserving core; alternative fixed anchor 9s/14s. These are heuristic context windows, not final story boundaries. Output stable candidate IDs, source clock, lane ranks/strengths, evidence references, availability, rationale, unverified status.
Complexity: grouping and ranking O(N log N), greedy selection O(KN), exploration O(RK log K), storage O(N+K+duration/300000). Potential quadratic if K grows with N. No explicit semantic novelty penalty, inference budgets, uncertainty quantification or calibrated probabilities yet. No model dependencies. Defaults remain experimental, not recommendation for production.
