# Experimental protocol
Run from repository root: PYTHONPATH=. python tests/test_radar_x.py -v ; PYTHONPATH=. python tests/ds01_benchmark.py > ds01-results.json . Windows PowerShell: $env:PYTHONPATH='.' then same python commands.
Five deterministic one-hour fixtures (seeds 11,12,15,17,19); 12 time blocks each, 12 random high-strength noise observations per block, quiet dialogue, nearby acoustic reaction and chat events; missing transcript/chat depending on seed. Gold assigned by generator, not discovery output, but observed evidence is constructed from gold and timing is patterned: intentionally not independent real-world data. Same existing Observation rows and absolute K for all four methods. Acoustic/visual extension tested separately, not in matched benchmark (baseline cannot represent these modalities). Eight configs incl four single changes to adaptive; 5 budgets, 200 runs.
Core hit >=80% covered by one proposal, context hit requires full essential interval plus core. Duplicate proxy extra event hits, multi-event-window proxy counts windows covering >1 gold event (NOT incorrect grouping rate). Total footage sum counts overlaps; no unique temporal coverage measurement. Runtime measured with tracemalloc instrumentation, peak Python allocations only, no process RSS or model cost. Baseline code copied exactly from pinned blob 82d8a4202333e4d7c30d68b7571cbb7eedb4a033, local lightweight matching Observation/Candidate and nearby_text shims (no transcript content); full repository suite unrun. Local experimental source blob matches remote ae07530b89d4e15424bdbe3c0568a730d7f32b60. 15 targeted unittest cases. No statistical significance claimed. No real footage, no human annotation, no semantic inference. Real benchmark must freeze independent gold before tuning; pair by VOD, stratify by modality, report both candidate count and total unique footage/inference time, include creator-disjoint held-out recordings.
