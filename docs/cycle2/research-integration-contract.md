# Research integration contract and DEEPSCOUT handoff

Base: `feat/director-first`, `24bf2f5f4ad2172e4b18728b198fe7d3e9d65aff`. Working branch: `work/cycle2-keystone`. Resolve delivered head with `git rev-parse work/cycle2-keystone`; implementation/checkpoint revisions are in final-engineering-report.md. DEEPSCOUT PR #12 arrived during delivery and was inspected; see deepscout-compatibility.md. Its prototype is not production-approved and is not merged into this branch.

Implemented and deterministically tested:

- `editorial_selection.read_selection` validates native candidate ledgers or lowers `director-selection/1` additively. The original report, proposals, reasons, verdicts, final boundaries, evidence refs, story beats, suggestions, confidence labels, modality availability, coverage and usage remain available. Scores stay null when unavailable. Candidate identity/source identity are preserved. Missing decisions become explicit abstentions.
- `director.production.verify_selection/export_selection` reuses Campaign, TranscriptIndex, enforce, Candidate duplicate rules and the existing manual renderer. It checks actual source hash/duration/track, transcript hash and cited text/times, recomputed final boundaries, campaign revision, exclusions, duplicate/clip limits and output hashes. A verified plan reaches framing/captions/audio/rendering and a pending human-review manifest. Selected-only exports, reject/abstain, zero clips and interrupted/cache reuse are supported. Partial discovery requires explicit export opt-in. Optional reviewed layout files use existing geometry validation. No model-produced FFmpeg commands are accepted.
- `director.semantic.BudgetPolicy` adds configurable discovery/investigation caps, final response reserve, call/runtime timeouts and per-phase accounting. The default total remains 120; one response is reserved when total permits. Validated cache keys still include source, provider fingerprint, phase, schema and full prompt. Requests are forbidden on the last available decision response. Discovery policy/order remains unchanged; partial ranges/counts are explicit.
- `research_interfaces.SemanticAudioProvider` is a protocol only. `semantic_audio` accepts optional providers, selected source audio track, bounded intervals and a rights reference; outputs available/unavailable state and cacheable simultaneous label/confidence observations. It installs/downloads nothing. Fakes verify multiple labels, unavailable state and cache validity.
- `research_interfaces.evidence_item/validate_evidence` provides `chomp-research-evidence/1`: content-derived stable ID, source identity, integer interval, modality, model fingerprint and provenance. Supported modalities include utterance, acoustic event, chat reaction, visual frame, motion, subject track, verified visual region, scene transition and OCR. Model confidences are not cross-provider calibrated probabilities.
- `research_interfaces.retrieve_frames/sample_times` reuses Director `extract_frame`, preserving actual decoded PTS, requested time, frame hash and decoder fingerprint. Sparse/candidate interval sampling, supplied scene boundaries, normalized protected boxes, bounded frame/interval budgets and verified cache reuse are supported. Scene detection and protected-region identification are **not** implemented. Retrieval is explicit and unavailable/invalid requests fail visibly.
- `research_interfaces.collect_candidates` preserves overlapping lane proposals, references and per-lane confidence without merging or ranking. Candidate caps report omitted counts. It is an extension point, not a new fusion algorithm.

Compatibility: existing `chomp-evidence/1`, editorial-plan and ShotComposer contracts are unchanged. The new research envelope is deliberately distinct and must be explicitly lowered into a future compatible Director/shot contract. A transcript cannot prove visual observation. Production semantic acceptance remains transcript-grounded; non-dialogue semantic acceptance is **not yet implemented**. Missing evidence requires abstention, retrieval or unresolved human review. Do not bypass utterance gates merely by relabeling a reference.

Benchmark commands and schema migrations are in chompbench-manual.md and annotation-guidelines.md. Existing ClipLedger/SubjectLock/layout evaluators remain authoritative. Synthetic A/B/C/D fixtures run without paid providers; no real-world precision/recall preference score exists without independent annotations. The full 24-VOD dataset and creator-disjoint human holdout are not available in this delivery.

Research questions: which discovery ordering works within fixed budgets; which acoustic/visual evidence warrants non-dialogue acceptance; how to calibrate/fuse lanes; how to request context adaptively; how to establish event identity across proposals; how to choose safe crops on transparent composites without losing gameplay context. Add experimental providers next to `research_interfaces.py`, and strategy policies around `scan_dialogue`/`investigate` behind explicit options. Keep deterministic renderer validation independent of provider reasoning.

Coordinate before editing `editorial_selection.py`, `director/production.py`, `director/semantic.py`, `director/clip.py`, `evaluation/benchmark.py` or `media.py`; these define the integration boundary. Do not modify shared attribution records on KEYSTONE's behalf. All local VODs, transcripts, response caches and comparison frames remain under ignored outputs or pre-existing private source directories; do not publish them.
