Tests, model notices and build manifests informed adoption decisions. Upstream code and weights were examined as references. The only Phase 1 runtime is the existing OpenCV and FFmpeg stack.

## Benchmark choices

Measure decoding and feature processing on the same source intervals at the same cadence. The Phase 1 engine uses the bundled 232,589-byte YuNet ONNX and small decoded frame batches on CPU. The optional U²-Net foreground model already has a separate pinned download. Compare stable-target visibility, track loss, time per source minute and peak memory before selecting any larger model. Use masked scene-change comparisons around verified cuts. Optical flow and persistent ID association need failure cases for texture loss and occlusion. SAM 2 and full YOLO-based pipelines have no local runtime benchmark in this gate.

The full clone revisions are available through each pinned source link and the local clone's Git metadata. Weight license claims apply to the named artifacts. A future integration must update the corresponding notice if weights or packaging change.

## Local GTA6 Clipper archive

The supplied `gta6-clipper-skill.zip` has SHA-256 `d0a291f34fa80551f23cd46fae2ef395c4c9d0ab5a2c0c59b141e5287437193d`. I inspected `layout.py`, `render.py`, `captions.py`, `moments.py` and `setup.sh` directly in the archive. The layout first searches for coherent borders or a stationary region around YuNet face boxes. It reuses corroborated boxes from other clips and temporally smooths camera state with a five-sample majority and a 2.5 s minimum segment. The renderer uses FFmpeg and produces ASS groups from timed words, with pauses and punctuation controlling grouping. Its macOS setup depends on Claude Code, faster-whisper, OpenCV, Pillow, yt-dlp and FFmpeg. The archive carries no license file. Keep it as a design reference for recurring camera geometry, subtitle grouping and separately configurable finishing.
