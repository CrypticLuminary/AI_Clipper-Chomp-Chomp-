# Synthetic syntax examples only

The two reaction templates illustrate a context/reaction/return sequence. Every time, box, identity and hash is invented. They are deliberately unrenderable: the zero hashes are placeholders and all semantic regions are unverified. Do not promote their geometry or times into Jay3, Emiru or another real source.

For an actual source, `chomp shots prepare` generates measured source metadata, its actual hash and a context-only starter. A controller supplies source-reviewed interval geometry. Give that pack and actual authorized visual evidence to any Director, which returns a native ShotPlan. Call `chomp shots validate` before rendering. See `docs/editing/shotcomposer.md` for the complete contract and workflow.

Native plans allow explicit output slots. The Director can move a source webcam to any slot, keep a reaction view, switch to a detail, return, or choose no effect. A request for an unavailable operator goes into `capability_requests`, never a raw FFmpeg expression.
